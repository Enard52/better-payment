Add the `multiTenant` plugin: dynamically resolves provider credentials per merchant for marketplaces and SaaS platforms, provides `payment.forTenant(id)`, caches provider instances with configurable TTL, routes 3D Secure callbacks, and tags operations and events with `tenantId`.
