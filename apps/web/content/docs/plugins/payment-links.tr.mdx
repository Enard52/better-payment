---

<Since version="0.12.0" />

Serbest çalışanlar (freelancer), küçük işletmeler ve müşteri destek ekipleri; özel bir e-ticaret ödeme sayfası geliştirmek zorunda kalmadan müşterilerine belirli bir tutar için doğrudan ödeme bağlantısı göndermek ister.

`paymentLinks` eklentisi, HMAC-SHA256 kullanarak şifreli imzalanmış linkler oluşturur, link durumunu (`open`, `paid`, `expired`, `cancelled`) yönetir ve ödeme uç noktalarını doğrudan [handler](/docs/concepts/handler) üzerinden sunar.

## Kurulum [#setup]

```typescript
import { betterPayment, iyzico } from 'better-payment';
import { paymentLinks } from 'better-payment/plugins';

export const payment = betterPayment({
  providers: {
    iyzico: iyzico({ /* ... */ }),
  },
  plugins: [
    paymentLinks({
      secret: process.env.LINK_SECRET!,
      baseUrl: 'https://shop.example.com/api/pay',
      defaultExpiresIn: '7d',
    }),
  ],
});
```

## Link Oluşturma [#creating-a-link]

```typescript
const link = await payment.links.create({
  amount: '250.00',
  currency: 'TRY',
  description: 'Invoice #42 - Web design',
  expiresIn: '7d', // e.g. '24h', '7d', or milliseconds
  singleUse: true, // default: true (marks link 'paid' after first successful charge)
});

console.log(link.url);
// → https://shop.example.com/api/pay/links/resolve?id=a1b2c3d4&sig=...
```

## Handler Uç Noktaları [#handler-endpoints]

Eklenti handler üzerinde iki uç nokta tanımlar:

### 1. `GET /links/resolve?id=:id`
Link bilgilerini çözer, HMAC imzasını doğrular ve geçerli bilgileri döner:

```json
{
  "id": "a1b2c3d4",
  "amount": "250.00",
  "currency": "TRY",
  "description": "Invoice #42 - Web design",
  "status": "open",
  "expiresAt": 1729800000000,
  "singleUse": true
}
```

### 2. `POST /links/pay`
Kart ve müşteri bilgilerini alır, link durumunu ve imzasını denetler ve tahsilatı gerçekleştirir:

```json
{
  "linkId": "a1b2c3d4",
  "paymentCard": { "cardNumber": "...", "expireMonth": "...", "expireYear": "...", "cvc": "..." },
  "buyer": { "id": "BY1", "name": "Ali", "surname": "Yılmaz", "email": "ali@example.com", "identityNumber": "...", "ip": "...", "city": "...", "country": "...", "gsmNumber": "...", "registrationAddress": "..." },
  "shippingAddress": { "contactName": "Ali Yılmaz", "city": "Istanbul", "country": "Turkey", "address": "..." },
  "billingAddress": { "contactName": "Ali Yılmaz", "city": "Istanbul", "country": "Turkey", "address": "..." }
}
```

Link `singleUse: true` ise, başarılı ödemenin ardından durumu `paid` yapılır ve mükerrer çekimler engellenir (`410 Gone`).

## Link Durumu ve İptal [#link-lifecycle--cancellation]

```typescript
// Query link status
const link = await payment.links.get('a1b2c3d4');
console.log(link?.status); // 'open' | 'paid' | 'expired' | 'cancelled'

// Cancel a link
await payment.links.cancel('a1b2c3d4');
```

## Seçenekler [#options]

| Seçenek | Varsayılan | Açıklama |
| --- | --- | --- |
| `secret` | — | HMAC-SHA256 imzası üretmek ve doğrulamak için gizli anahtar |
| `baseUrl` | — | Handler'ın çalıştığı temel URL (örn. `'https://shop.example.com/api/pay'`) |
| `defaultExpiresIn` | `'7d'` | Varsayılan link geçerlilik süresi (`'24h'`, `'7d'` veya ms) |
| `store` | `MemoryPaymentLinkStore` | `PaymentLinkStore` arayüzünü uygulayan özel veritabanı deposu |
