title: MCP Sunucusu
description: Better Payment'ı yapay zekâ ajanları (AI agents) için Model Context Protocol (MCP) sunucusu olarak sunun.
---

<Since version="0.12.0" />

`mcp` eklentisi, Better Payment kütüphanesini HTTP JSON-RPC 2.0 üzerinden standart bir Model Context Protocol (MCP) sunucusuna dönüştürür. Bu sayede yapay zekâ asistanları ve otonom ajanlar (Claude Desktop, Cursor, Copilot veya özel LLM ajanları) ödeme durumunu sorgulayabilir, BIN kontrolü yapabilir, taksit seçeneklerini listeleyebilir ve güvenli bir şekilde iade veya iptal işlemlerini yürütebilir.

## Kurulum

```typescript
import { betterPayment, iyzico } from 'better-payment';
import { mcp } from 'better-payment/plugins';

export const payment = betterPayment({
  providers: {
    iyzico: iyzico({ /* ... */ }),
  },
  plugins: [
    mcp({
      path: '/mcp',
      readOnly: false,
      authorize: async (req, toolName) => {
        // Yazma işlemlerini (iade, iptal) yetkilendirme ile koruyun
        const token = req.headers.authorization?.replace('Bearer ', '');
        return token === process.env.MCP_ADMIN_SECRET;
      },
      onToolCall: async ({ tool, params, result, isError }) => {
        console.log(`MCP Aracı çalıştırıldı: ${tool}`, { params, isError });
      },
    }),
  ],
});
```

`betterPayment` HTTP işleyicisi (Next.js, Fastify, Express, Hono, Elysia vb.) ile bağlandığında aşağıdaki uç noktalar otomatik olarak kaydedilir:
- `POST /mcp` — JSON-RPC 2.0 protokol uç noktası (`initialize`, `notifications/initialized`, `tools/list`, `tools/call`).
- `GET /mcp/info` — Sunucu durumu ve metaveri sorgulama uç noktası.

## Kullanılabilir Araçlar

MCP sunucusu aşağıdaki araçları kullanıma sunar:

| Araç | Tür | Açıklama |
| ---- | --- | -------- |
| `getPayment` | Okuma | Sağlayıcı ve ödeme kimliğine göre ödeme durumu ve detaylarını sorgular. |
| `binCheck` | Okuma | Kartın ilk 6-8 hanesine göre banka, marka, kart tipi ve kart ailesi bilgilerini getirir. |
| `installmentInfo` | Okuma | Belirtilen BIN ve tutar için mevcut taksit seçeneklerini ve vade oranlarını listeler. |
| `refund` | Yazma | Ödemenin tamamını veya bir kısmını iade eder. Yetkilendirme kontrolü gerektirir. |
| `cancel` | Yazma | İşlemi gün sonu öncesinde iptal eder. Yetkilendirme kontrolü gerektirir. |

## Güvenlik Önlemleri

- **Kart Verisi Temizliği:** Hassas kart verileri (`cardNumber`, `cvv`, `expiryMonth`, `expiryYear`, `card`) yanıt gövdesinden otomatik olarak temizlenir, böylece PAN verilerinin LLM modellerine sızması önlenir.
- **Yazma Yetkilendirmesi:** Kritik işlemler (`refund`, `cancel`), `authorize` geri çağrımı ile yetkilendirme doğrulaması gerektirir. `readOnly: true` yapılandırıldığında yazma araçları araç listesinden tamamen çıkarılır.
- **Denetim Günlüğü:** `onToolCall` kancası, çalıştırılan her aracın adını, parametrelerini, temizlenmiş sonucunu ve çalışma süresini yakalar.

## Seçenekler

| Seçenek | Tür | Varsayılan | Açıklama |
| ------- | --- | ---------- | -------- |
| `name` | `string` | `'better-payment-mcp'` | Başlatma sırasında bildirilen MCP sunucu adı. |
| `version` | `string` | `'1.0.0'` | İstemciye bildirilen MCP sunucu sürümü. |
| `path` | `string` | `'/mcp'` | MCP JSON-RPC uç noktası için temel yol. |
| `readOnly` | `boolean` | `false` | `true` ise yazma araçları (`refund`, `cancel`) hariç tutulur. |
| `authorize` | `(req, tool) => boolean \| Promise<boolean>` | — | Yazma işlemleri için yetkilendirme doğrulama fonksiyonu. |
| `onToolCall` | `(details) => void \| Promise<void>` | — | Her araç çağrısından sonra tetiklenen denetim kancası. |
