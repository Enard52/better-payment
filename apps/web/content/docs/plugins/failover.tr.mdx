---
title: Sağlayıcı Yedekleme (Failover)
description: Sağlayıcı kesintilerinde veya geçici hatalarda ödemeyi otomatik olarak yedek sağlayıcıya yönlendirin, dahili circuit breaker ile gereksiz beklemeleri önleyin.
---

<Since version="0.12.0" />

Birden fazla sanal POS veya ödeme kuruluşu ile çalışan işletmeler, birincil sağlayıcıda yaşanan kesintiler, ağ zaman aşımları ya da geçici ağ geçidi hataları yüzünden satış kaybedebilir. `failover` eklentisi, geçici bir altyapı hatası tespit ettiğinde ödemeyi belirlediğiniz sırayla yedek sağlayıcılara yönlendirerek yüksek erişilebilirlik (high availability) sağlar.

En önemlisi, failover **sıfır çift çekim garantisi** sunar: sonucu belirsiz olan işlemleri (`NETWORK_ERROR` veya bankanın çekimi yapmış olabileceği `pending` durumları) kesinlikle tekrar denemez.

## Kurulum

```typescript
import { betterPayment, iyzico, paytr, parampos } from 'better-payment';
import { failover } from 'better-payment/plugins';

const payment = betterPayment({
  defaultProvider: 'iyzico',
  providers: {
    iyzico: iyzico({ apiKey: '...', secretKey: '...' }),
    paytr: paytr({ merchantId: '...', merchantKey: '...', merchantSalt: '...' }),
    parampos: parampos({ clientCode: '...', guid: '...' }),
  },
  plugins: [
    failover({
      order: ['iyzico', 'paytr', 'parampos'],
      // Yalnızca çekimin kesinlikle gerçekleşmediği altyapı hataları
      on: ['PROVIDER_ERROR', 'PROVIDER_UNAVAILABLE', 'TIMEOUT_BEFORE_SEND'],
      circuitBreaker: {
        failures: 5,
        window: '1m',
        cooldown: '5m',
      },
      onSwitch: ({ from, to, operation, attempt }) => {
        console.warn(`[failover] ${operation} işlemi ${from} üzerinden ${to} sağlayıcısına aktarıldı (${attempt}. deneme)`);
      },
    }),
  ],
});

// iyzico geçici bir hata verirse otomatik olarak paytr üzerinden tamamlanır
const result = await payment.createPayment({
  orderId: 'SIPARIS-101',
  amount: 250,
  currency: 'TRY',
  paymentCard: { ... },
});
```

## Nasıl Çalışır?

1. **Before hook & Circuit Breaker kontrolü**: Seçili sağlayıcının devre kesicisi (circuit breaker) açıksa, gereksiz ve zaman alıcı bir HTTP çağrısı yapılmadan işlem doğrudan `order` listesindeki ilk sağlıklı sağlayıcıya yönlendirilir.
2. **Çalıştırma**: Sağlayıcı çağrılır.
3. **After hook & Yedek geçişi**: Sağlayıcı `on` listesindeki bir geçici hata ile dönerse, hata circuit breaker'a kaydedilir, sıradaki uygun yedek sağlayıcı çağrılır.
4. **Güvenlik koruması**: Sonucu belirsiz (`status: 'pending'` veya `code: 'NETWORK_ERROR'`) işlemler asla tekrar denenmez. Müşteri kart retleri (`INSUFFICIENT_FUNDS`, `CARD_DECLINED`, `EXPIRED_CARD`) de ret olarak korunur, başka sağlayıcıya aktarılmaz.

## Seçenekler

| Seçenek | Varsayılan | Açıklama |
| ------- | ---------- | -------- |
| `order` | tüm tanımlı sağlayıcılar | Öncelik sırasına göre sağlayıcı kimlikleri veya dinamik fonksiyon `(ctx) => string[]` |
| `on` | `PROVIDER_ERROR`, `PROVIDER_UNAVAILABLE`, `TIMEOUT_BEFORE_SEND`, `SYSTEM_ERROR`, `500-504` | Yedeklemeyi tetikleyen hata kodları |
| `operations` | `['createPayment', 'authorize']` | Yedeklemenin geçerli olduğu operasyonlar |
| `circuitBreaker` | `{ failures: 5, window: '1m', cooldown: '5m' }` | Devre kesici eşiği, zaman penceresi ve bekleme süresi |
| `onSwitch` | — | Sağlayıcı değiştiğinde tetiklenen geri çağırma fonksiyonu |

## Devre Kesici Durumu ve Yönetimi

Eklenti, ödeme nesnesine bir `failover` alanı ekler:

```typescript
// Tüm sağlayıcıların devre kesici durumlarını inceleyin
const circuits = payment.failover.status();
// {
//   iyzico: { state: 'open', failures: 5, openUntil: 2026-10-18T04:10:00.000Z },
//   paytr: { state: 'closed', failures: 0, openUntil: null }
// }

// Planlı bakım sırasında bir sağlayıcıyı manuel olarak devre dışı bırakın
payment.failover.trip('iyzico', '15m');

// Devre kesiciyi sıfırlayın
payment.failover.reset('iyzico');
payment.failover.reset();
```
