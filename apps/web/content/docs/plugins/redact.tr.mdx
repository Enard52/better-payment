<Since version="0.12.0" />

Ödeme istekleri kredi kartı numaraları (PAN), güvenlik kodları (CVC/CVV), son kullanma tarihleri, T.C. Kimlik Numarası (TCKN), telefon numaraları ve adres bilgileri taşır. Bu verilerin açık halde log dosyalarına yazılması veya iç olay dinleyicilerine (event listeners) dağıtılması **PCI DSS** (Gereksinim 3: Kart Hamili Verilerinin Korunması) ve **KVKK** (Kişisel Verilerin Korunması Kanunu) mevzuatlarına aykırıdır.

`redact` eklentisi, hassas kart ve kimlik verilerinin log çıktılarında, ödeme olaylarında ve denetim izlerinde otomatik olarak maskelenmesini sağlar; bu esnada ödeme sağlayıcısına (sanal POS) iletilen orijinal ödeme isteğine kesinlikle dokunmaz.

## Kurulum

```typescript
import { betterPayment, iyzico } from 'better-payment';
import { redact } from 'better-payment/plugins';

const payment = betterPayment({
  providers: {
    iyzico: iyzico({ apiKey: '...', secretKey: '...' }),
  },
  plugins: [
    redact({
      // Kart numarası maskeleme stili
      card: 'first6last4', // örn: 545454******5454
      // Metin içerisindeki özel desenler (11 haneli TCKN varsayılan olarak maskelenir)
      custom: [/\b\d{11}\b/g],
    }),
  ],
});

// Olay dinleyicileri maskelenmiş güvenli veriyi alır
payment.on('payment.succeeded', (event) => {
  // event.request.paymentCard.cardNumber === '545454******5454'
  // event.request.paymentCard.cvc === '***'
  // event.request.buyer.identityNumber === '<redacted>'
  console.log('Ödeme tamamlandı:', event.request);
});
```

## Nasıl Çalışır?

1. **Banka / Sağlayıcıya Değişmeden İletim**: Gerçek kart ve müşteri verileri doğrudan ödeme sağlayıcısına iletilir, ödeme akışında hiçbir kesinti veya hata oluşmaz.
2. **Olay Yükü Maskeleme**: `after` kancasında, olay dinleyicilerine (`payment.succeeded`, `payment.failed` vb.) iletilen `request` ve `result` nesnelerinin kopyaları maskelenir.
3. **Logger Sarmalama**: `betterPayment({ logger })` ile bir logger yapılandırıldıysa, `debug`, `info` ve `error` metodları sarmalanarak loglanan tüm metin ve meta veriler hassas anahtarlara ve PAN desenlerine karşı filtrelenir.

## Seçenekler

| Seçenek | Varsayılan | Açıklama |
| ------- | ---------- | -------- |
| `fields` | `['cardNumber', 'cvc', 'cvv', 'expireMonth', 'expireYear', 'identityNumber', 'gsmNumber', 'phoneNumber', 'password', ...]` | Değerleri otomatik olarak maskelenecek nesne anahtarları |
| `card` | `'first6last4'` | Kart maskeleme formatı: `'first6last4'`, `'last4'`, `'none'` veya özel `(pan) => string` |
| `custom` | `[/\b\d{11}\b/g]` | Metin içerisinde maskelenecek ek RegExp desenleri (örn: 11 haneli TCKN) |
| `maskString` | `'<redacted>'` | Genel maskeleme metni |
| `redactLogger` | `true` | Log çıktılarını otomatik maskelemek için yapılandırılmış logger'ı sarmalar |
| `redactEvents` | `true` | Olay dinleyicilerine gitmeden önce olay yükünü maskeler |

## Manuel Maskeleme Yardımcısı

Eklenti, uygulama kodunuzda kullanabilmeniz için ödeme nesnesine bir `redact` alanı ekler:

```typescript
// Kart numarasını maskeleme
payment.redact.maskCard('5528790000000008');
// => '552879******0008'

// İsteğe bağlı nesneleri veya logları maskeleme
const safeObject = payment.redact.mask({
  orderId: 'SIP-1',
  cardNumber: '5528790000000008',
  cvc: '123',
  identityNumber: '12345678901',
});
// => { orderId: 'SIP-1', cardNumber: '552879******0008', cvc: '***', identityNumber: '<redacted>' }
```
