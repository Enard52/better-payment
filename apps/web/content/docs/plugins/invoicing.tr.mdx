<Since version="0.12.0" />

Türkiye'de her ticari satış için müşteriye e-Fatura veya e-Arşiv faturası düzenlenmesi zorunludur. `invoicing` eklentisi fatura süreçlerini arka planda otomatikleştirir: başarılı bir ödemenin ardından seçtiğiniz entegratör (ör. Paraşüt) üzerinden faturayı düzenler; iade gerçekleştiğinde ise iade faturası keser veya faturayı iptal eder.

Fatura oluşturma işlemi ödeme tamamlandıktan sonra arka planda asenkron olarak yürütülür; müşterinin ödeme deneyimini kesinlikle yavaşlatmaz veya bekletmez.

## Kurulum [#setup]

```typescript
import { betterPayment, iyzico } from 'better-payment';
import { invoicing, parasut } from 'better-payment/plugins';

export const payment = betterPayment({
  providers: {
    iyzico: iyzico({ /* ... */ }),
  },
  plugins: [
    invoicing({
      adapter: parasut({
        clientId: process.env.PARASUT_CLIENT_ID!,
        clientSecret: process.env.PARASUT_CLIENT_SECRET!,
        username: process.env.PARASUT_USERNAME!,
        password: process.env.PARASUT_PASSWORD!,
        companyId: process.env.PARASUT_COMPANY_ID!,
      }),
      // Custom mapping from payment and basket items to invoice fields
      map: (payment) => ({
        buyer: {
          name: `${payment.buyer?.name} ${payment.buyer?.surname}`,
          taxNumber: payment.buyer?.identityNumber,
        },
        vatRate: 20, // 20% KDV
      }),
      onRefund: 'return-invoice', // 'return-invoice' | 'cancel' | 'none'
      retry: { attempts: 3, delay: 1000 },
      onInvoiceCreated: (invoice, event) => {
        console.log(`Invoice issued: ${invoice.invoiceNumber} for payment ${event.paymentId}`);
      },
      onInvoiceFailed: (error, event) => {
        console.error(`Invoice failed for payment ${event.paymentId}:`, error);
      },
    }),
  ],
});
```

## Özellikler [#features]

- **Asenkron Çalışma:** `payment.succeeded` ve `refund.succeeded` olaylarını dinler. Müşteri ödeme onayını anında alır, fatura entegratör üzerinden arka planda kesilir.
- **Otomatik Yeniden Deneme:** Entegratör API'sinde geçici kesinti veya kota aşımları yaşandığında yapılandırılan aralıklarla otomatik olarak yeniden dener.
- **İade Senaryoları (`onRefund`):**
  - `'return-invoice'` (varsayılan): İade edilen tutar kadar iade faturası oluşturur.
  - `'cancel'`: Entegratör üzerinden orijinal satış faturasını iptal eder.
  - `'none'`: İadelerde herhangi bir fatura işlemi yapmaz.
- **Manuel Tekrar Deneme:** Başarısız faturalar hafızada saklanır ve `payment.invoicing.retry(paymentId)` ile istenildiği an tekrar denenebilir.
- **Genişletilebilir Adaptör Mimarisi:** Resmi **Paraşüt** adaptörünün yanı sıra Logo, Uyumsoft, Foriba/Sovos, BirFatura gibi sistemler için genişletilebilir `InvoicingAdapter` arayüzü sunar.

## Fatura Yönetim API'si [#invoicing-management-api]

Eklenti, `payment.invoicing` nesnesi üzerinden yönetim fonksiyonları sunar:

```typescript
// Look up an invoice by payment ID
const invoice = payment.invoicing.get('pay-12345');
console.log(invoice?.invoiceNumber, invoice?.status);

// List all generated invoices
const allInvoices = payment.invoicing.list();

// List invoices that failed after all retry attempts
const failed = payment.invoicing.getFailed();

// Manually retry a failed invoice
const recovered = await payment.invoicing.retry('pay-12345');
console.log('Recovered invoice:', recovered.invoiceNumber);

// Manually cancel an invoice
await payment.invoicing.cancel('pay-12345', 'Customer requested return');
```

## Seçenekler [#options]

| Seçenek | Tür | Varsayılan | Açıklama |
| ------- | --- | ---------- | -------- |
| `adapter` | `InvoicingAdapter` | *(Zorunlu)* | Fatura entegratör adaptörü (ör. `parasut`). |
| `map` | `Function` | — | Alıcı bilgileri, kalemler ve KDV oranını özelleştiren eşleme fonksiyonu. |
| `onRefund` | `'return-invoice' \| 'cancel' \| 'none'` | `'return-invoice'` | İade başarılı olduğunda yapılacak işlem. |
| `retry` | `{ attempts?: number, delay?: number }` | `{ attempts: 3, delay: 1000 }` | Geçici API hatalarında yeniden deneme politikası. |
| `defaultVatRate` | `number` | `20` | Varsayılan KDV oranı yüzdesi (%20). |
| `onInvoiceCreated` | `Function` | — | Fatura başarıyla oluşturulduğunda tetiklenen fonksiyon. |
| `onInvoiceFailed` | `Function` | — | Yeniden denemeler tükendiğinde tetiklenen fonksiyon. |
