Die Referenz wird mit TypeDoc aus demselben Quellstand wie diese Website erzeugt.
Sie umfasst das Hauptpaket, `client`, `testing`, `plugins` und jedes Framework-
Adapter. Nutze die Suche, um exportierte Funktionen, Klassen und Typen zu finden. Die
Referenz ist englisch und wird von allen Dokumentationssprachen gemeinsam genutzt.

Stable- und Beta-Bereitstellungen erzeugen ihre eigene Referenz. Öffne sie nach der
Versionsauswahl, damit die API zur verwendeten Paketversion passt.

Für Integrations-Durchgänge beginne mit dem [Schnellstart](/docs/quick-start).
Der [Typüberblick](/docs/reference/types) erklärt die häufigsten Request- und Response-Strukturen.

## Für KI-Assistenten [#for-ai-assistants]

Jeder Build erzeugt außerdem `/llms.txt`, einen Index der englischen und türkischen
Dokumentation, und `/llms-full.txt`, die vollständige englische Dokumentation als
Markdown. Der Index verlinkt saubere Markdown-Kopien der einzelnen Seiten.
Beta-Bereitstellungen liefern diese Dateien unter `/beta` und verlinken die
Dokumentation dieser Version.

Diese Dateien werden aus den Docs erzeugt und nicht separat gepflegt.
